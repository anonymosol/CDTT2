# Tác vụ so sánh thẻ game và bộ lọc

Mục 7 trong khung sườn giao Thành viên 3 chạy GitHub Copilot Agent trong VS Code cho tác vụ thẻ game và bộ lọc. Thành viên 4 thực hiện một lượt độc lập bằng công cụ thứ hai.

Nhóm có bản đặc tả ở `docs/specs/task1-game-card-filter.md` trên nhánh `docs/task1-spec`. Nhóm cần duyệt và dùng cùng bản đặc tả cho cả hai lượt thử. Kết quả triển khai ứng dụng Khám phá bằng Codex được ghi tại `docs/AI_LOG.md`. Lượt thử Copilot, lượt thử công cụ thứ hai và so sánh theo đặc tả đang chờ thực hiện.
