# Data sources and licenses

Record each game's metadata and rules source, its license or permission basis,
attribution requirements, and the date it was checked.

**General basis (applies to every row below):**

- Every game in this batch is a **traditional / public-domain game**. Game
  rules as such (mechanics, procedures) are not copyrightable; what we must
  not copy is *copyrighted expression* of rules (commercial rulebooks, boxed
  manual text).
- All rule documents in `data/rules/` are **written by the team in our own
  wording**, using the cited article as factual reference. Wikipedia text is
  CC BY-SA 4.0 — if we paraphrase wording beyond plain facts from it, the
  rule document must link the source and keep the share-alike spirit.
- `games.csv` metadata (player counts, durations, difficulty) are facts.
